# Artificial Intelligence Lab Codes Description

1. Depth First Search (DFS) and Breadth First Search (BFS)
Description

This program implements two important graph traversal algorithms:

Depth First Search (DFS)
Breadth First Search (BFS)

The algorithms are used to traverse or search vertices in an undirected graph or tree data structure.

DFS explores nodes deeply before backtracking.
BFS explores all neighboring nodes level by level.
Applications
Path finding
Social network analysis
Web crawling
Network broadcasting
Technologies Used
Python
Graph Data Structure
Queue and Recursion

---------------------------------------------------------
2. A* (A Star) Algorithm
Description

This program implements the A* search algorithm used for solving game search and pathfinding problems.

A* finds the shortest and most optimal path between source and destination using:

Actual path cost (g)
Heuristic estimated cost (h)

Formula:

f(n)=g(n)+h(n)

Applications
GPS navigation
Game AI
Robot navigation
Maze solving
Technologies Used
Python
Priority Queue
Heuristic Functions

---------------------------------------------------------
3. Greedy Search Algorithms
a) Selection Sort
Description

Selection Sort repeatedly selects the minimum element and places it at the correct position.

Applications
Small dataset sorting
Educational understanding of sorting algorithms
b) Minimum Spanning Tree (MST)
Description

This algorithm connects all graph vertices with minimum total edge weight and without cycles.

Applications
Network design
Cable routing
Road map optimization
c) Single Source Shortest Path Problem
Description

Finds the shortest distance from one source node to all other nodes.

Applications
GPS systems
Routing protocols
Navigation systems
d) Job Scheduling Problem
Description

Schedules jobs to maximize profit within deadlines using greedy strategy.

Applications
CPU scheduling
Task management
Project planning
e) Prim’s Minimal Spanning Tree Algorithm
Description

Prim’s algorithm builds MST by continuously adding the minimum weight edge.

Applications
Communication networks
Electrical grids
f) Kruskal’s Minimal Spanning Tree Algorithm
Description

Kruskal’s algorithm constructs MST by selecting smallest edges without forming cycles.

Applications
Transportation systems
Network optimization
g) Dijkstra’s Algorithm
Description

Dijkstra’s algorithm finds the shortest path from source to all vertices in a weighted graph.

Applications
Google Maps
Network routing
Delivery systems

4. Constraint Satisfaction Problem (N-Queens / Graph Coloring)
a) N-Queens Problem
Description

This program solves the N-Queens problem using:

Backtracking
Branch and Bound

The goal is to place N queens on a chessboard so that no queens attack each other.

Applications
AI planning
Resource allocation
Puzzle solving
b) Graph Coloring Problem
Description

Assigns colors to graph vertices such that no adjacent vertices have the same color.

Applications
Map coloring
Scheduling
Register allocation in compilers
